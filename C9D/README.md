# C9D - Инструмент для анализа сетевой безопасности

Этот инструмент использует ИИ для анализа сетевых данных и сохранения информации о хостах и их взаимодействиях в графовую базу данных Neo4j для анализа информационной безопасности.

## Функциональность

- Анализ сетевых логов и извлечение информации о хостах
- Определение взаимодействий между хостами
- Оценка уровня угрозы для взаимодействий
- Хранение данных в графовой базе Neo4j с различными типами узлов (Host, MAC, IP, Hostname, Software, Port)
- Визуализация графа взаимодействий через веб-интерфейс

## Требования

- Python 3.8+
- Gemini API ключ
- Локально запущенная база данных Neo4j

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас запущена локальная база данных Neo4j (по умолчанию на bolt://localhost:7687)

3. Настройте переменные окружения в файле `.env`:
```
GEMINI_API_KEY=ваш_ключ_доступа_к_Gemini
```

## Использование

### Обработка файла

```bash
python main.py путь/к/файлу/с/данными.log
```

### Запуск визуализации

```bash
python visualize.py
```
Затем откройте в браузере http://localhost:5000

Или используйте новую визуализацию в стиле Neo4j:

```bash
python run_visualization.py
```
Затем откройте в браузере http://127.0.0.1:8000

### Структура данных в Neo4j

Программа создает узлы различных типов:
- `Host`: информация о хостах с полями:
  - host_id: уникальный ID машины
  - ips: список IP-адресов
  - macs: список MAC-адресов
  - hostnames: список доменных имен
  - ports: список открытых портов
  - software: список программного обеспечения
  - os: операционная система
  - anomalies: список аномалий
  - summary: краткое описание

- `MACAddress`, `IPAddress`, `Hostname`, `Software`, `Port`: узлы соответствующих типов

- Отношения между узлами:
  - `HOST_HAS_MAC`: связь между хостом и MAC-адресом
  - `HOST_HAS_IP`: связь между хостом и IP-адресом
  - `HOST_HAS_HOSTNAME`: связь между хостом и именем хоста
  - `HOST_RUNS_SOFTWARE`: связь между хостом и программным обеспечением
  - `HOST_HAS_PORT`: связь между хостом и открытым портом
  - `INTERACTED_WITH`: взаимодействие между хостами с описанием, уровнем угрозы и типом действия

## Архитектура

- `generator/generator.py`: работа с Gemini API
- `prompt.py`: обработка промптов и извлечение данных
- `graph_db.py`: работа с графовой базой Neo4j
- `main.py`: основной скрипт
- `visualize.py`: веб-интерфейс для визуализации графа
